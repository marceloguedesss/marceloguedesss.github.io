CASE_001 / projeto-aujuda / public
Academic project // C // terminal application

Aujuda!

Um sistema criado para organizar o cadastro e a busca de animais perdidos dentro de uma comunidade, usando uma aplicação de terminal como exercício prático de programação estruturada em C.

LANGUAGEC
INTERFACETerminal / CLI
CONTEXTProjeto acadêmico
STATUSRepositório público
01 // PROBLEMA

Uma ideia simples para um problema real.

O projeto nasceu da proposta de criar uma ferramenta que pudesse ajudar uma comunidade a organizar informações sobre animais desaparecidos. A ideia central era permitir que usuários cadastrassem animais e que outras pessoas realizassem buscas com base em características conhecidas.

02 // IMPLEMENTAÇÃO

O que a versão atual faz.

A implementação pública organiza usuários e animais por meio de structs e vetores em memória. O fluxo começa pelo cadastro ou login do usuário e, depois da autenticação, permite cadastrar um animal ou pesquisar os registros existentes.

Cadastro de usuárioNome, e-mail e senha, com confirmação da senha antes do registro.
LoginBusca do e-mail cadastrado e comparação da senha para liberar o fluxo principal.
Cadastro de animalNome, espécie, raça, cor e último local em que o animal foi visto.
Busca combinadaFiltros simultâneos por espécie, raça, cor e local.
Busca tolerante a caixaA pesquisa compara texto ignorando diferenças entre maiúsculas e minúsculas.
Interface em terminalMenus, validação básica de opções e navegação por uma aplicação CLI.
03 // FLUXO

Do acesso à busca.

O fluxograma elaborado na fase de concepção registra a lógica geral pretendida para o sistema: entrada do usuário, autenticação, escolha entre cadastro e busca e finalização da ação.

01Usuário acessa o sistema e entra na área de autenticação.
02Após o login, escolhe entre cadastrar um animal ou realizar uma busca.
03ANo cadastro, informa as características do animal e seu último local conhecido.
03BNa busca, combina filtros para reduzir os resultados exibidos.
04O sistema apresenta a confirmação do cadastro ou os animais compatíveis encontrados.
04 // TÉCNICA

Conceitos praticados.

Mais do que o produto final, o Aujuda! funciona como registro da minha evolução em fundamentos de C e organização de um programa maior que exercícios isolados.

StructsModelagem separada de usuários e animais.
ArraysEstruturas em memória para manter os registros durante a execução.
FunçõesSeparação das responsabilidades de cadastro, login, busca e interface.
StringsUso de strcmp, strcpy, strlen e comparação caractere a caractere.
Controle de fluxoLoops, condições e validações das opções inseridas pelo usuário.
Terminal LinuxUso de recursos como termios, unistd.h e limpeza de terminal.

05 // EVOLUÇÃO

Conceito inicial × versão pública.

O planejamento original era mais amplo do que a implementação atual. Para apresentar o projeto com precisão, separo aqui o que fazia parte da concepção e o que efetivamente está disponível no repositório.

PLANEJAMENTO INICIAL
  • ID único de 10 dígitos por animal
  • Persistência em banco de dados
  • Informações de contato associadas aos resultados
IMPLEMENTAÇÃO ATUAL
  • Cadastro e login de usuários em memória
  • Cadastro de animais com struct
  • Busca por espécie, raça, cor e local
  • Comparação textual sem diferenciar caixa
06 // PRÓXIMOS PASSOS

Como eu evoluiria o projeto hoje.

Se eu retomasse o Aujuda!, os próximos passos seriam persistir os dados entre execuções, separar o projeto em múltiplos arquivos, reforçar validações de entrada e evoluir o modelo de autenticação. Uma versão web também permitiria transformar a ideia original em uma experiência mais acessível para uma comunidade real.
