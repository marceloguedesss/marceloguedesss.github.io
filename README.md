# Guedes Portfolio V5 — Aujuda Case

Esta versão transforma o Aujuda! em um case interativo dentro do próprio portfólio.

## O case apresenta
- problema e objetivo
- funcionalidades realmente presentes no código público
- fluxograma original
- conceitos de C praticados
- diferença entre planejamento inicial e implementação atual
- próximos passos
- link direto para o repositório

## Observação de precisão
O documento inicial previa ID único e persistência/banco de dados.
Esses elementos não aparecem na versão pública atual do código, então foram
apresentados como planejamento inicial, e não como funcionalidades implementadas.
